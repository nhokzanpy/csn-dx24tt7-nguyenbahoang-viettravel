# 🇻🇳 VietTravel

VietTravel là website giới thiệu những địa điểm du lịch nổi bật tại Việt Nam.

Website được xây dựng bằng HTML, CSS và JavaScript thuần, tập trung vào giao diện đơn giản, responsive và các chức năng tìm kiếm địa điểm.

## 🌐 Live Demo

👉 https://nhokzanpy.github.io/VietTravel/

## ✨ Tính năng

- 🔎 Tìm kiếm địa điểm
- 🗺️ Lọc địa điểm theo tỉnh/thành
- 🔤 Sắp xếp địa điểm A → Z và Z → A
- 🔄 Xóa bộ lọc nhanh
- 📄 Phân trang danh sách địa điểm
- 🖼️ Xem chi tiết địa điểm bằng Modal
- 🌙 Dark Mode / Light Mode
- 💾 Ghi nhớ chế độ giao diện
- 📱 Responsive cho PC và thiết bị di động
- ⬆️ Nút quay lại đầu trang
- 🧭 Điều hướng nhanh giữa các khu vực

## 🛠️ Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- JSON
- Git
- GitHub
- GitHub Pages

Không sử dụng framework hoặc thư viện JavaScript bên ngoài.
